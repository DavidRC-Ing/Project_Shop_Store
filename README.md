# 🛍️ Project Shop Store
**Análisis Avanzado de Pruebas A/B para E-commerce**

![Dashboard](https://via.placeholder.com/900x400.png?text=Dashboard+A%2FB+Testing)

---

## 📋 Descripción del Proyecto
**Project Shop Store** es un análisis exhaustivo de pruebas A/B realizado para una tienda en línea internacional, enfocado en evaluar el impacto de un **sistema de recomendaciones mejorado** y un **embudo de pago optimizado** sobre las tasas de conversión de usuarios en la **Unión Europea**.

---

## ✨ Características Principales
- 🔍 Exploración de datos y calidad de eventos  
- 🧹 Limpieza y normalización de datos  
- 📊 Pruebas estadísticas automatizadas (grupos control vs experimental)  
- 🎯 Sistema de recomendaciones mejorado  
- 💳 Optimización del checkout y embudo de pago  
- 🌍 Enfoque en usuarios de la UE  

---

## 🛠️ Stack Tecnológico
`Python` · `Pandas` · `NumPy` · `SciPy` · `Matplotlib` · `Seaborn` · `Jupyter Notebook`

---

## 📊 Resultados Principales
| Resultado | Hallazgos |
|-----------|-----------|
| ↗️ Aumento de Actividad | Incremento general en la actividad de usuarios |
| 📊 Conversión | No se encontraron diferencias significativas entre grupos |
| 🎯 Insights | Identificación de áreas de mejora para futuras pruebas |
| 📋 Recomendaciones | Aumentar tamaño de muestra, considerar variables externas |

---

## 🎯 Conclusiones
- **Diseño Experimental Robusto**: clave para obtener resultados confiables  
- **Tamaño de Muestra**: necesario incrementarlo para detectar efectos más sutiles  
- **Variables Externas**: incluir factores contextuales que influyen en usuarios  
- **Métricas Adicionales**: explorar KPIs más allá de la conversión tradicional  
- **Base para Decisiones**: fundamentos sólidos para nuevas funcionalidades
